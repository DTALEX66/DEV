# AI 行为规则

## 核心原则
- **禁止跨目录操作**：AI 代理只能在当前项目目录内执行任务。
- **禁止删除文件**：任何情况下不得删除项目中的文件或目录。
- **禁止修改 C 盘**：所有操作限定在 D:\DEV 范围内。
- **禁止自动推送**：未经明确授权，不得 push 到 GitHub。

## 工作范围
- 仅限 weird-choice-game 项目目录
- 如需访问其他目录，必须用户明确授权

## 变更规则
- 任何代码变更需记录在 CODEX_TASK.md
- 修改前先检查 DEV_PLAN.md 确认计划
- 每次只做一个任务
- 所有修改必须可回滚
