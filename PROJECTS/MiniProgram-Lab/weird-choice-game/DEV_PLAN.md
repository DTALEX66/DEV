# 开发计划：规则怪谈互动小程序 MVP

## 项目目标
构建一款「规则怪谈」风格的互动叙事小程序 MVP，用户通过阅读剧情并选择选项推进故事。

## 技术栈（待定）
- 前端：微信小程序 / Uniapp
- 数据格式：JSON（story.json）
- 状态管理：页面级 props / store

## 里程碑

### Phase 1 — 项目初始化 ✅
- 目录结构搭建
- 配置文件编写
- 最小剧情数据定义

### Phase 2 — 核心引擎（当前）
- 剧情加载器：从 story.json 读取章节
- 选项渲染组件：动态渲染选项按钮
- 章节跳转逻辑：根据选项 next 字段跳转
- 结局渲染：结局页面的展示与重新开始

### Phase 3 — 体验完善
- 音效 / 震动反馈
- 存档 & 读档
- 多结局分支路线图
- 暗黑 / 怪谈风 UI 主题

### Phase 4 — 测试 & 发布
- 黑盒测试（TEST_CHECKLIST.md）
- 真机调试
- 小程序提审
